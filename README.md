# Projeto MauiAppHoTel

## 📌 Sobre o projeto

Este projeto foi desenvolvido durante o curso Técnico em Desenvolvimento de Sistemas da ETEC, utilizando .NET MAUI, C# e XAML.

O objetivo foi praticar o desenvolvimento de aplicativos, trabalhando na criação e personalização de interfaces e na organização dos arquivos do projeto.

## 🛠️ Tecnologias utilizadas

- C#
- XAML
- .NET MAUI
- Visual Studio

## 📱 Desenvolvimento do projeto

Durante o desenvolvimento, foram realizadas atividades como:

- Criação e organização das telas do aplicativo.
- Desenvolvimento das interfaces utilizando XAML.
- Personalização de cores, textos, botões, bordas e espaçamentos.
- Organização dos elementos visuais para melhorar a apresentação das telas.

## 📂 Estrutura do projeto

- `Views/`: pasta utilizada para organizar as telas do aplicativo.
- `.xaml`: arquivos responsáveis pela definição da interface visual.
- `.xaml.cs`: arquivos C# associados às telas, utilizados para implementar comportamentos e eventos.
- `App.xaml`: arquivo de configuração de recursos gerais da aplicação.

## 📚 Aprendizados

Com este projeto, pude praticar a criação de interfaces com XAML, conhecer melhor o funcionamento do .NET MAUI e desenvolver minhas habilidades na organização e personalização de aplicativos.
